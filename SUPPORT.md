# Support

## How to get help


> **Languages**: [English](SUPPORT.md) · [中文](SUPPORT.zh-CN.md)
There are several ways to get help, depending on what you need:

### Questions and how-to

* **GitHub Discussions** — for open-ended design questions, "how do I…" and
  best-practice questions. Open one
  [here](https://github.com/tyj1987/broker/discussions).
* **Documentation** — most questions are answered here:
  - [Quickstart](docs/QUICKSTART.md) — install and first call
  - [SDK Reference](docs/SDK-REFERENCE.md) — Python / Go / VSCode SDKs
  - [Threat Model](docs/THREAT-MODEL.md) — security model and trust boundaries
  - [FAQ](docs/FAQ.md) — frequently asked questions
  - [Runbook](RUNBOOK.md) — day-to-day operations

### Bug reports

* **GitHub Issues** — for reproducible bugs and feature requests. Use the
  [Bug Report](../../issues/new?template=bug_report.yml) template.
* **Before filing** — search [existing issues](../../issues) first; someone
  may have already reported it.

### Security issues

* **Do not file a public GitHub issue for security vulnerabilities.**
* Email **security@broker.example.com** (PGP key in `.well-known/pgp-key.asc`)
* See [`SECURITY.md`](SECURITY.md) for the full policy, scope, and the
  $5,000 bug bounty program.

## Commercial support

This project is open-source under MIT. Commercial support, custom feature
development, and production deployment assistance are available — contact
**sales@broker.example.com**.

## Community guidelines

* Be respectful and constructive
* Assume good faith
* No spam, self-promotion, or off-topic content
* Follow the [Contributor Covenant](https://www.contributor-covenant.org/)
  code of conduct
