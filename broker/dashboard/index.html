快速上手 / Quick Start

        
从客户端调用 / From a client

        
# 健康检查
secret-broker health

# 代理模式（AI 推荐，密钥不离开 broker）
secret-broker proxy github GET /repos/tyj1987/sops-age-template

# 注入环境变量运行子进程
secret-broker exec --env "GH_TOKEN" -- git push origin main

# 拉明文（仅白名单）
secret-broker get github.pat


        
管理员操作 / Admin operations

        
# 签发新客户端证书
secret-broker pki issue-client --cn client.tyj-laptop --role developer --register

# 吊销证书
secret-broker pki revoke --fingerprint AB:CD:EF:...

# 列出所有客户端
secret-broker pki list


        
安全模型 / Security model

        
    
          
  • AI 客户端永远不直接拿到明文密钥。代理模式下，AI 只看到外部 API 的请求/响应。
    • 
          
  • mTLS 双向认证：每台设备一张 client cert，丢失可秒吊销。
    • 
          
  • 所有 resolve / proxy / rotate 调用都落审计日志 audit/audit-YYYY-MM-DD.jsonl。
    • 
          
  • 策略引擎：每个客户端有 allowed_resolve / allowed_proxy 白名单。
