# Secret Broker Desktop

The Windows and Linux desktop client loads only bundled UI assets. Its native bridge is limited to health checks, typed operation creation, and storing or deleting the operation API key in the operating system credential store. It exposes no arbitrary URL, file, shell, clipboard, cookie, or remote-content capability.

Windows is the first release target. Linux acceptance targets Ubuntu 24.04 LTS x64 after the Windows package passes signing and update verification.
