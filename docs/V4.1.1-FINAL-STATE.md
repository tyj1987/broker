## SDK V4.1.1 unified contract

All 4 SDKs now expose:
- **`BrokerError`** (single class, replaces 6 typed classes per SDK)
- Fields: `op`, `status`, `code`, `requestId`, `retryAfter`, `body`
- Getter: `is_retryable` (5xx / 429 / connection → `true`)
- Methods: `toString()`, `toJSON()` / `to_map()` / `to_dict()` (body omitted)
- **Auto-redact body on construction** (defense in depth)
- **`parseBrokerError(status, headers, body, op)`** factory
- **Built-in retry**: 5xx / 429 / connection with exponential backoff
  (500ms → 1s → 2s), honors `Retry-After` response header
- **`BrokerConnectionError`** (network failures, always retryable)
